**A powerful MIDI controller, sound editor, performance tool and step sequencer for the Roland JD-Xi, with beta support for the Roland JD-XA.**

JD-Xi Remote brings deeper control of your Roland synthesizer to your Android phone or tablet. Edit sounds, control effects, manage patches, create sequences and perform live using an interface designed to make the hardware more accessible and enjoyable.

The app communicates directly with the synthesizer over USB MIDI, using standard MIDI messages and Roland SysEx for detailed parameter control.

Whether you're designing sounds, building patterns or performing live, JD-Xi Remote gives you more hands-on control without constantly navigating the synthesizer's small display and menus.

## Choose your synth

The app opens on a landing page where you choose **JD-Xi** or **JD-XA**. The synth you used last is marked, and a model switch at the top of each page lets you change between the two at any time. The Android Back button returns from a synth page to the landing page.

| | JD-Xi | JD-XA (beta) |
|---|---|---|
| Status | Full support | Beta, see [JD-XA support](#jd-xa-support-beta) |
| Parts | 4 (Digital 1, Digital 2, Analog, Drums) | 8 (Analog 1-4, Digital 1-4) |
| Step sequencer | Native 4-track (Kotlin / Jetpack Compose) | 16-track, in the web interface |
| Programs for pattern chaining | A01-H64 | INT / USB A01-P16 |
| DX7 import | Yes | Not available |

## Features

### Synthesizer & Sound Editor

Explore and edit the JD-Xi's sound engine through a visual interface.

- Control Digital Synth 1, Digital Synth 2 and Analog Synth parts.
- Read the currently active sound directly from the JD-Xi.
- Edit oscillator, filter, amplifier and LFO parameters.
- Adjust cutoff, resonance and envelope settings.
- Access detailed ADSR controls.
- Edit individual digital partials or link partials together.
- Access advanced sound parameters through the full parameter editor.
- Send parameter changes directly to the synthesizer using MIDI SysEx.
- Edit arpeggio settings.
- Play and audition sounds using the on-screen keyboard.

The editor provides both simplified controls for quick adjustments and advanced editing for detailed sound design.

### Mixer & Effects

Control your synth's mix and effects without navigating through hardware menus.

- Adjust levels for individual synthesizer parts.
- Read current mixer settings from the connected synth.
- Control effect parameters from the dedicated FX interface.
- Make adjustments while playing.
- Optionally retain your preferred mixer settings when switching patterns.

Designed for quick adjustments during sound design, rehearsals and live performance.

### Native 4-Track Step Sequencer (JD-Xi)

JD-Xi Remote includes a native Android step sequencer, built with Kotlin and Jetpack Compose.

The sequencer follows the JD-Xi's four-part architecture:

| Track | MIDI Channel |
|---|---|
| Digital Synth 1 | 1 |
| Digital Synth 2 | 2 |
| Drums | 10 |
| Analog Synth | 3 |

**Sequencer features:**

- 16, 32, 48 or 64 steps.
- Piano-roll style note editing.
- Dedicated drum grid with JD-Xi drum sounds.
- Adjustable note velocity and duration.
- Tempo control from 40 to 240 BPM.
- Swing adjustment.
- Individual track mute controls.
- Play and stop controls.
- Optional MIDI clock and transport synchronization.
- Eight local pattern memory slots.
- Automatic local storage of the current sequence.
- Ability to send sequencer playback to the JD-Xi for recording into its internal pattern sequencer.

Create musical ideas on your phone or tablet and hear them immediately through the connected synthesizer.

### Live Performance & Pattern Launcher

The Performance section is designed for playing and arranging patterns live.

Assign up to six programs to performance slots and switch between them during playback.

- Six configurable pattern slots.
- Visual indication of the current and next pattern.
- Queued pattern changes synchronized with musical timing, with a visible queue.
- Pattern transitions at the end of the current pattern.
- Adjustable tempo and timing options.
- MIDI clock synchronization, either generated by the app or followed from the synth.
- Punch In FX pads: hold a pad to trigger effects such as drum rolls, filter sweeps, pitch dives, stutters and gates, and release to return to normal.
- MIDI panic / all-notes-off function.

This makes it possible to create longer musical arrangements from existing patterns and move between sections during a live performance.

#### How pattern switching works

A Program Change makes the synthesizer load a whole program and stop its sequencer. The synth's own smooth "queued" switch cannot be triggered over MIDI, so the app emulates the queue: it counts MIDI clock, sends Bank Select and Program Change a short time before the downbeat (the **Switch lead**) and sends Start on the downbeat.

- **Switch lead** defaults to 170 ms on the JD-Xi (200 ms on the JD-XA), long enough for the synth to load a program.
- **Measure** plays a few test switches on the first slot, times the first note that comes back and sets the Switch lead to the shortest value that still gives a clean start, plus a small safety margin.
- After every switch the status line shows how long the first note took to arrive, so a bad lead is easy to spot.
- The synth mutes the last part of the old pattern during a switch, so leave the final step or two of a pattern empty, or use a smaller lead.
- Pattern chaining needs the app clock (synth Sync = SLAVE). When following the synth's clock (Sync = MASTER) the synth ignores Start, so the pattern must be started on the synth after a switch.

### Patch Management

Manage your own sounds directly from the app.

- Read the current sound from the synth.
- Save custom patches locally.
- Name and organize your sounds.
- Mark favorite patches.
- Search and filter saved sounds.
- Restore saved patches to the synthesizer.
- Export patch collections as JSON files.
- Import previously saved patch collections.

Experiment with sound design while keeping a personal collection of your favorite patches.

### Yamaha DX7 Patch Import (JD-Xi)

Explore classic FM synthesizer sounds with the integrated DX7 import tool.

- Import Yamaha DX7 `.syx` files.
- Support for individual voices and 32-voice banks.
- Inspect the structure of imported DX7 sounds.
- Convert selected voice characteristics into JD-Xi-compatible digital tone parameters.
- Transfer the resulting tone to the JD-Xi's temporary sound memory.

**Note:** The Yamaha DX7 and Roland JD-Xi use fundamentally different synthesis architectures. Imported DX7 sounds are approximations rather than exact reproductions.

## JD-XA support (beta)

JD-XA support is new and **in beta**. It is built from Roland's published MIDI documentation (SysEx model ID 0F), but it has had limited testing on real hardware. Behaviour may differ between units and firmware versions, so try it on a copy of your program first. Bug reports are very welcome.

**What is available on the JD-XA page:**

- Eight parts (four analog, four digital) with an 8-part mixer and visualizer.
- Performance page with six slots and queued pattern switching, using programs INT / USB A01-P16 (Bank Select MSB 85).
- Punch In pads using documented JD-XA program addresses.
- 16-track step sequencer (eight synth parts and eight MIDI Control tracks) with live playback and Standard MIDI File export.
- Tone editor, FX controls and patch browser.
- **JD-XA STUDIO** tab: program select, SysEx tools, patch manager (read, backup, verify, restore), a read-only SysEx inspector, tone editor (CC / NRPN), program library, live test and MIDI monitor.
- MIDI Player and the same themes, Size setting and visualizer as the JD-Xi page.

**Beta limitations:**

- The JD-XA step sequencer is a local editor. It does not write patterns to the JD-XA's internal pattern memory; use the MIDI file export and the synth's own SMF import instead.
- The native Android sequencer is JD-Xi only.
- DX7 import is not enabled for the JD-XA.
- Edits go to the temporary program. Use the JD-XA's own WRITE function to keep a change.
- JD-XA STUDIO includes functions that write to the synth (patch restore, advanced SysEx write, FX write). Use **Identify** first, back up the program you are about to change, and treat these as experimental.
- Some displayed editor values are local values and not read back from the synth.

More detail is in [docs/JD-XA_README.md](docs/JD-XA_README.md).

## USB MIDI Connection

JD-Xi Remote communicates with the synthesizer through a direct USB connection.

**Requirements:**

- Android device running Android 7.0 or newer.
- Roland JD-Xi or JD-XA synthesizer.
- USB cable and USB-OTG adapter, or a compatible USB-C connection.
- Android device with USB host support.

The JD-Xi may need to be configured to use its generic USB MIDI driver mode.

Once connected, the app can exchange MIDI messages with the synthesizer, including Roland SysEx messages for detailed sound editing. Only the page for the selected model sends to the synth, so JD-Xi commands are not sent while you are on the JD-XA page.

## How the App Works

JD-Xi Remote combines two technologies in one Android application.

**Remote interface**

The sound editor, performance tools, mixer, JD-XA support and other controller functions use an embedded web-based interface running inside an Android WebView.

A custom MIDI bridge connects the interface to Android's native MIDI API, allowing communication with the synthesizer, including SysEx messages.

**Native sequencer**

The four-track JD-Xi step sequencer is implemented natively in Kotlin using Jetpack Compose.

It communicates with the synthesizer through the same underlying USB MIDI connection.

This hybrid design combines a flexible editing interface with native Android sequencing functionality.

## Who Is It For?

JD-Xi Remote is designed for:

- **Sound designers** who want easier access to synthesizer parameters.
- **Live performers** who want convenient pattern switching, punch-in effects and mixer control.
- **Electronic musicians** creating sequences, beats and arrangements.
- **JD-Xi and JD-XA owners** who want to explore more of their synthesizer's capabilities.
- **Musicians using phones or tablets** as additional controllers in their hardware setup.

The application is intended as a companion to the physical Roland synthesizer, not as a software synthesizer replacement.
